# Project Structure  

## Overview  
This project follows strong OOP principles with clear separation of concerns.  

## Directory Layout

project/
├── src/ # Source code (tracked in git)
│ ├── config/ # Configuration classes
│ ├── data/ # Data handling classes
│ ├── features/ # Feature extraction classes
│ ├── models/ # Model classes
│ ├── training/ # Training classes
│ ├── evaluation/ # Evaluation classes
│ └── utils/ # Utility classes
│
├── data/ # Data files (ignored in git)
├── models/ # Model artifacts (ignored in git)
├── logs/ # Logs (ignored in git)
├── results/ # Results (ignored in git)
├── configs/ # Configuration files (tracked)
├── scripts/ # Executable scripts (tracked)
├── tests/ # Unit tests (tracked)
└── notebooks/ # Jupyter notebooks (tracked)
